# 规则变更 01｜主卡组与灵体同色 ≥60%

> 状态：已写入引擎并成为**硬约束**（`js/engine/rules.js` 的 `DECK_RULES.spiritColorRatio`），旧构筑规则于 2026-11-14 废除，旧脚本与旧战绩整体归档到 `_oldrule_2026-11-13/`。
> 待办：0.2 版规则书正文 §2.1 仍写着「不要求与灵体同色」，需由作者手工改一行（见文末，替换文本已备好）。

## 一、规则文本

**构筑时，主卡组中与所选灵体同色的卡牌必须至少占 60%（向上取整）。本规则在四种模式中一律生效，与初始生命、起手张数、卡组上下限无关。**

例：

| 主卡组 | 同色下限 | 说明 |
|---:|---:|---|
| 40 张 | 24 张 | 恰好 60% 即合法 |
| 50 张 | 30 张 | |
| 57 张 | 35 张 | 34 张＝59.6%，不合法 |
| 60 张 | 36 张 | |

## 二、计数口径

1. **只按卡牌自身的颜色字段计**。混色卡（如 `荒原雷兽`，黄 3＋灰 2）按主色黄计，不按费用里的两种颜色各算一次。
2. **灰是中性色**。灰卡只在灵体本身为灰（`荒原旅人`）时算作同色；其他七色配灰卡，灰卡一律不计入同色。
3. **灵体本身不计入分子与分母**。它不在主卡组里，也不占张数。
4. 分母是主卡组实际张数，不是上限 60。40 张的精简构筑只需 24 张同色，不需要凑到 36 张。
5. 同名 ≤4、不得投入灵体、`duo` 的「恰好 2 种非灰颜色各 ≥10 张」等旧约束全部照旧，本规则与其他约束**同时**校验。

## 三、与旧条款的关系

0.2 版规则书 §2.1 原文：

> 第二版不限制主卡组颜色，也不要求与灵体同色。颜色身份由高同色费用、灵体能力与卡牌配合维持。

本规则**取代**该段后半句。「不限制颜色种类」仍然成立——你可以自由掺色，但同色比例必须 ≥60%。因此灵体不再是可以随手取用的「通用挂件」：灵体的颜色就是卡组的身份。

## 四、引擎实现

```js
// js/engine/rules.js
export const DECK_RULES = Object.freeze({ sameNameMax: 4, spiritColorRatio: 0.6 });

validateDeck(deck, mode, { spirit: '余烬执火者' })
// → { ok, errors, spiritColor: '红', sameColor: 35, sameColorNeed: 32 }
```

- `createGame` 会用 `spiritA` / `spiritB` 的颜色校验；预组没有具名灵体，改用 `PRECON_COLORS` 的主色。
- 组卡器在卡组面板显示「同色 X/Y · Z%」，不达标即标红。
- **没有绕过开关**：`allowLegacyDeck` 已于 2026-11-14 删除，非法卡组一律在开局时抛出。
- 回归测试：`tools/test.mjs` 的「构筑：与灵体同色的卡牌须至少 60%」一项，覆盖 24/40 合法、23/40 不合法、灰灵体换色、未指定灵体不校验、开局拦截五个点。

## 六、全量重跑（2026-11-14）

旧规则连同旧数据一并废除：12 份脚本全部重新派发（12 个模型拿含本规则的简报重新组卡、重写脚本），循环赛与瑞士轮重跑。

| 项 | 结果 |
|---|---|
| 合规 | 12/12（同色 65%—84%，最低 KIMI 2.8preview，最高 MIMO-v2.6-pro） |
| 循环赛 | 四模式各 264 局，共 1056 局，异常 0 |
| 瑞士轮 | 四模式各 3 届 × 5 轮 × 6 桌，共 360 局 |
| 加权冠军 | KIMI 3.1pro「赤蓝燃穿」71.8%（红 34／蓝 16，同色 68%） |
| 末位 | hy4「赤烬疾袭」17.7%（红 34／蓝 10／灰 6） |
| 主色分布 | 红 7／绿 4／白 1（旧规则下为红 9／绿 1／白 2） |

三件值得记的事：

1. **规则没有削弱红色，但杀死了「红色挂件」。** 红系仍是多数（7/12），但每份都必须真的把 65%—84% 押在红上。
2. **单色成体系的构筑受益。** 绿从 1 份涨到 4 份；白墙同色 45/56＝80% 轻松达标，稳居第三。
3. **灰卡是隐性成本。** 灰卡在同色统计里一律不计，hy4 带 6 张灰等于白让 12% 配额，从旧规则的第 6（52.7%）掉到末位（17.7%）。

完整战绩与逐份组卡说明见 `agents/README.md` 与 `agent-progress/`。

# SE01《第一声回响》· 数值审计

> 用途：证明新卡数值落在结构文档 §5 的模型内，并把超模项挑出来，而不是让它们藏在卡表里。
> 口径：应有总量 ＝ 基准（2250F − 250）− 词条与效果折价；实际总量 ＝ 攻击力 ＋ 生命力。
> 容差：±500 视为合格；±501—1000 标「偏」；>1000 标「超」。

灵体无身材，不做总量验算。只核一件事：**专属能力的每回合价值应接近 1 费**，因为通用能力（横置抽 1）本身就是 1 费级。

## 五、审计结论

| 项 | 数量 |
|---|---:|
| 受检新卡 | 42 灵像 ＋ 30 灵感 ＋ 15 灵性 ＋ 8 灵体 ＝ 95 |
| 灵像超模（>+1000） | 3（王牌巨象、共鸣武士、雷霆战将） |
| 灵像偏弱（<−500） | 3（大图书馆长、渡魂人、梦藤巨像） |
| 灵感卡偏强 | 1（连锁雷鸣） |
| 灵性卡高风险 | 4（骸骨祭坛、浮空书库、织梦机、篝火营地） |
| 灵体偏强 | 2（陵园看守者、根脉育苗者） |

三张超模全部是既有示例，四张高风险灵性卡全部是本弹新增。**这意味着首轮测试的主要风险不在「新卡太强」，而在「灵性卡这一类型本身太强」。** 若只能改一处，优先加待拍板 C 的回响限次，而不是逐张砍数值。

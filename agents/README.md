## 三、各模型的组卡思路与对战思路

每份的完整设计说明在 `agent-progress/<id>.md`，下面是浓缩版。

### KIMI 3.1pro ·「赤蓝燃穿」· 50 张（红 34／蓝 16）· 余烬执火者

**组卡**：红色打主线，火焰鸟、地狱犬、火球术、爆燃四张各 4 张；蓝色只占 16 张，功能是过牌与节奏（智慧之光、奥术飞弹满编）。同色 34/50＝68%，刚好压线——它没有为了凑比例牺牲曲线。
**对战**：低费灵像持续施压，红色直伤负责收尾，蓝色维持手牌不断档。四种模式全部前七，是唯一主责 duo 却在标准（72.7%）与速攻（79.5%）都拿第一的脚本。

### MiniMax M3 ·「余烬共鸣」· 50 张（红 41／黑 4／灰 5）· 余烬执火者

**组卡**：红 41 张走「自燃」路线，灰烬小僧、燃魂、火球术、地狱犬、烈焰斗士满编；混色燃魂 4 张、血焰狂徒 3 张。同色 41/50＝82%，全场第二高（仅次于 MIMO 的 84%），却仍带双色件。
**对战**：让自己的单位替我挨刀，把每次献祭换成对手生命卡组上的伤口，灵体每回合给一个单位 +1 冲击。duo 第一（72.7%），长局第三。

### deepseek v4.1flash ·「圣所铁壁·二阶冲击」· 56 张（白 45／黄 11）· 圣所守夜人

**组卡**：白色 45 张，光能守护者、圣光战将、圣所守卫、晨祷侍从等守护单位与圣光打击、净化仪式满编，黄色只补 11 张。同色 45/56＝80%。
**对战**：守护＋自愈的墙同时承担打点与阻挡，雷铸天兵把墙抬成冲击 2，靠免费治疗与生命补充把对手拖死。长局第二（70.5%）、双色第四，是本轮最稳的非冠军。

### GLM5.3 ·「根脉奔流」· 50 张（绿 34／白 16）· 根脉育苗者

**组卡**：幼苗守望者、自然生长、部落祭司、丰收、森林战将五张满编，混色守林圣骑士 2、生命之泉 2 用于补白。绿 34 张刚过 68%。
**对战**：用灵质加速突破「每回合 1 张灵质」的硬上限，跳两回合费用让冲击 2 的超冲击巨兽提前登场。长局第一（72.7%）、速攻第三，四模式均值 3.42 全场最好。

### MIMO-v2.6-pro ·「烬火速攻」· 50 张（红 42／黑 8）· 余烬执火者

**组卡**：同色率全场最高（42/50＝84%），十张卡满编：火焰鸟、地狱犬、灰烬小僧、烈焰斗士、爆燃、血怒、火球术、燃魂、自杀式袭击、灵质榨取。黑色只有 8 张，纯粹补解。
**对战**：低费预制／敏捷打手每回合抢脸，燃魂、火球术、焚尽烧血，灰烬小僧连续献祭；速攻第二（72.7%）、标准第二。

**组卡**：幼苗守望者、部落祭司、自然生长、森林战将、王牌巨象、全面成长六张满编，白色只放圣光打击与新人冒险者各 4。
**对战**：灵体每回合横置加速并抽牌，快速拍出带预制·超冲击·践踏的森林战将与王牌巨象，绕过阻挡直击生命。双色第三（70.5%）、长局第六。

## 四、结果与观察

完整战绩见 `agent-progress/ladder.md`，原始数据见 `ladder.json`。每模式 132 局双循环，四模式共 1056 局，异常 0。

**一、同色约束没有削弱红色，但杀死了「红色挂件」。** 12 份里仍有 7 份以红为主色（上届是 9 份），区别在于上届很多卡组只是把红当主力牌、颜色随手掺；这届红系必须真的把 65%—84% 押在红上。绿从 1 份涨到 4 份、白 1 份——单色成体系的构筑（绿 ramp、白墙）反而更容易满足比例，这是规则带来的结构性偏移。

**二、冠军易主，而且换成了双色。** 新冠军是 KIMI 3.1pro「赤蓝燃穿」71.8%（红 34／蓝 16），旧冠军 deepseek v4.1flash 的白墙掉到第三（61.4%）。冠军在四个模式里没有一个低于第七，靠的是「没有短板」而不是某一模式压倒性。

**三、上届亚军的掉队最能说明规则的代价。** step5preview 旧版 57 张里只有 32 张绿（56%），靠白绿混用拿到 71.8%；新规则下必须收到 42/60（70%），同一套思路只剩 50.9%。而同样是绿 ramp 的 GLM5.3 把绿压到 34/50 后反而在长局拿第一（72.7%）——**不是绿色变弱了，是「靠掺色补强」这条路被封了**。

**四、hy4 从 52.7% 掉到 18.6%，是全场最大落差。** 它新版是红 34／蓝 10／灰 6，灰卡占了 12%，四模式全在后段。灰卡在同色统计里一律不计，等于白白让掉 6 张配额——这是新规则下最典型的一种失血方式。

**五、MiniMax M3.1flash 从垫底升到第七，值得单独记。** 上届它 9.5%、被判定「思路对、执行脱节」；这届它自己在设计说明里写，改的是「从不设灵质、常年只有 1 费」这个死穴，策略框架没动。**同一套判断，把执行补上就从 9.5% 到 52.7%**——上届的垫底不是判断错，是实现错。

**六、红系内部的差距比颜色之间还大。** 红系七份从 71.8%（KIMI 3.1pro）到 18.6%（hy4），差 53 个百分点。**在主色相同的前提下，决定胜负的是曲线与满编选择，不是颜色本身。**

**一、稳定与冠军仍然是两件事。** GLM5.3 四模式均值 3.84 最好（长局与双色都是并列第 3，没有一个模式掉出前五），但循环赛加权只排第四；KIMI 3.1pro 均值 3.92 紧随其后，却拿了加权冠军。和上届 glm53flash「最稳但只夺 1 冠」是同一个现象。

**三、hy4 的失败不是「选错模式」。** 它主责 standard，标准第 11、长局 11.33、双色 12.00，四模式均值 11.08。它的脚本没有执行缺陷，是构筑本身在同色约束下失去了冗余。

**四、样本量提醒。** 瑞士轮每模式 3 届 × 5 轮 × 6 桌 = 90 局，比循环赛的 264 局/模式少得多，名次波动大；两个赛制结论冲突时以循环赛的加权胜率为准，瑞士轮只用来看「在不同对手编排下是否稳定」。

## 六、接口约定

五件导出，缺一不可：

```js
export const meta = { id, model, modelId, name, desc, primaryMode, modes };
export const deck = { 卡名: 张数 };      // 或卡名数组
export const spirit = '圣所守夜人';       // 八色灵体选 1
export const color = '白';                // 主色，只影响显示与灵能池键名
export function choose(view, moves) { return moves[i]; }
```

硬约束：零依赖、无副作用、无模块级可变状态、必须返回 `moves` 里的元素、不得抛异常、单次决策 50ms 内。卡组另须满足 40—60 张、同名 ≤4、**与灵体同色 ≥60%**。

完整定义见 `agents/brief/01-接口约定.md`。

## 九、与旧规则那一届的对照

| 项 | 旧规则（2026-11-13） | 新规则（2026-11-14） |
|---|---|---|
| 构筑约束 | 同名 ≤4，不限颜色 | 同名 ≤4 ＋ 与灵体同色 ≥60% |
